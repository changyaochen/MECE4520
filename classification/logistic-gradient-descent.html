Gradient descent for logistic regression

This explorer fits a logistic-regression model for the course-defined high-CO label using turbine inlet temperature (TIT). It uses standardized TIT, so the two fitted coefficients have a convenient common scale.

TipWhat to watch

Choose the initial coefficients and learning rate, then take one step at a time. The red point traces the path downhill across the binary-cross-entropy surface; the panel on the right records the loss after each update. Adjust the surface-view-angle slider to inspect the same path from another direction; it does not change the optimization.

\[ \begin{aligned} \tilde{x}_i &= \frac{\mathrm{TIT}_i-\overline{\mathrm{TIT}}}{s_{\mathrm{TIT}}},\\ p_i &=\sigma(\beta_0+\beta_1\tilde{x}_i),\\ \boldsymbol{\beta}^{(t+1)} &=\boldsymbol{\beta}^{(t)}-\eta\nabla\mathcal{L}_{\mathrm{BCE}}. \end{aligned} \]
