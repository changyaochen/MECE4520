Exploring classification thresholds

This explorer uses the TIT-based high-CO logistic model on the training set. It follows one decision threshold as it changes the ROC curve, the precision–recall curve, and F1 score at the same time.

TipWhat to watch

Start with a very high threshold: no observations receive a high-CO label. As the threshold decreases, the model produces more alerts. The ROC curve traces true-positive against false-positive rate; the precision–recall curve shows the same alerts from a different perspective. F1 summarizes the balance between precision and recall.

The slider lowers \(\tau\) in evenly spaced increments from 1 to 0. Each point uses all observations whose predicted probability is at least \(\tau\); the same set of alerts drives all three views.
