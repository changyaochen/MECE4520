Problem 1, item 3 — expected reasoning (same for every student)

Expected: No — p = 0.12 is insufficient evidence to reject H₀ at α = 0.05; it does not prove μ = 60 mg/m³. A defensible conclusion: the data are consistent with μ = 60, but other mean values remain compatible.

Method, rounding, and acceptable variants
  • Seed rule: seed = int(uni[-4:]) — the last four characters of the UNI, parsed as an integer (leading zeros dropped: ab0042 → seed 42). The field above accepts any trailing digit run and uses its last four digits, i.e. exactly the assignment's rule.
  • Sampling: data.loc[data["campaign_year"] == 2014, "NOX"].sample(n=80, random_state=seed), the assignment's code path. Seeded pandas sampling is version-stable.
  • Statistics: mean and sample SD (ddof=1); SE = SD/√80; 95% CI via 1.96·SE (normal approximation). The t-interval (t = 1.99045, df = 79) and the t-test are also acceptable — they differ in the second decimal at most.
  • Rounding: estimate/CI endpoints 2 dp, p-values 3 significant digits (or < 0.001). Accept ±0.01 on 2-dp values (a student using SE rounded to 3 dp may be off by 0.01 in the last place).
  • If a student computes the CI from their own rounded mean/SE, endpoints may drift by 0.01 in the last place; the tolerance above covers it.
  • Sample SD uses ddof=1 (pandas default). Students using numpy.std without ddof=1 report SD ≈ 0.06 lower (e.g. 10.01 vs 10.07) and a correspondingly narrower CI — acceptable if internally consistent.
