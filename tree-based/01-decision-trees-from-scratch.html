Decision tree is the type of algorithm that generates prediction following a sequence of rules. In this notebook, we will code up a simple decision tree algorithm, to predict whether a gas-turbine operating observation has a high-CO emission.

We will first work through the first two splits using Gini impurity. Then we will turn that logic into a recursive algorithm that can grow a tree to any chosen depth, before comparing it with scikit-learn. The goal is to understand the splitting logic before relying on a library implementation.

What is a decision tree?

A decision tree repeatedly divides the observations into smaller regions. Each division asks a yes-or-no question about one feature—for example, whether turbine inlet temperature (TIT) is below a particular value. A new observation follows the applicable branches until it reaches a final region, called a leaf.

  • The root is the first question, applied to every observation.
  • An internal node is a later question that applies only to the observations that reached it.
  • A leaf makes the final prediction. For binary classification, it can report the fraction of positive-label observations in its region, or assign the majority class.

For this notebook, the binary target is represented by the labels 0 and 1.

1. Set up the classification task

Each row in the dataset records one gas-turbine operating observation. high_co is our binary target. We offer the tree the measured operating quantities, but exclude CO itself because the target was defined from that measurement.

We reserve 30% of the usable observations as a test set. We will build the tree only with the training observations, then check its simple held-out accuracy at the end.

2. Measure class mixing with Gini impurity

A tree divides the observations into regions. For a region (R) containing (K) classes, let (p_{R,k}) be the fraction of observations in class (k). The canonical Gini impurity is

\[ G(R) = 1 - \sum_{k=1}^{K} p_{R,k}^{2}. \]

For our binary target, let (q_R) be the fraction of observations with label 1. The formula becomes

\[ G(R) = 1-q_R^2-(1-q_R)^2 = 2q_R(1-q_R). \]

It is zero when a region contains only one class, and largest when the two classes are evenly mixed. A classification tree chooses the split that produces the largest reduction in the sample-size-weighted Gini impurity.

def gini_impurity(labels: pd.Series | np.ndarray) -> float:
    """Compute binary Gini impurity for one region.

    Args:
        labels: Binary labels in the region.

    Returns:
        The region's Gini impurity.
    """
    positive_fraction = np.mean(labels)
    return float(2 * positive_fraction * (1 - positive_fraction))


def region_summary(labels: pd.Series | np.ndarray) -> dict[str, float | int | str]:
    """Summarize a region using its observed labels.

    Args:
        labels: Binary labels in the region.

    Returns:
        Sample count, positive-label fraction, Gini impurity, and majority-class label.
    """
    positive_fraction = float(np.mean(labels))
    return {
        "samples": len(labels),
        "positive-label fraction": positive_fraction,
        "Gini impurity": gini_impurity(labels=labels),
        "majority class": 1 if positive_fraction >= 0.5 else 0,
    }

3. Score one proposed split

Suppose we propose splitting turbine inlet temperature (TIT) at 1076.95 °C. The observations at or below the cutpoint form the left region; the rest form the right region.

The loss after a split is the weighted average of the two child impurities:

\[ G_{\mathrm{after}} = \frac{n_L}{n}G(R_L) + \frac{n_R}{n}G(R_R). \]

The resulting Gini decrease is (G(R)-G_{}).

def score_split(
    feature_values: pd.Series, labels: pd.Series, threshold: float
) -> tuple[dict[str, float], pd.Series, pd.Series]:
    """Score one binary cutpoint with weighted Gini impurity.

    Args:
        feature_values: Values of one candidate feature in the parent region.
        labels: Binary labels in the same row order.
        threshold: Values at or below this cutpoint go to the left child.

    Returns:
        Split metrics plus the labels in the left and right child regions.
    """
    left_labels = labels[feature_values <= threshold]
    right_labels = labels[feature_values > threshold]
    n_total = len(labels)

    weighted_child_gini = (
        len(left_labels) / n_total * gini_impurity(labels=left_labels)
        + len(right_labels) / n_total * gini_impurity(labels=right_labels)
    )
    parent_gini = gini_impurity(labels=labels)
    return (
        {
            "parent Gini": parent_gini,
            "weighted child Gini": weighted_child_gini,
            "Gini decrease": parent_gini - weighted_child_gini,
        },
        left_labels,
        right_labels,
    )

proposed_threshold = 1076.95
score, left_labels, right_labels = score_split(
    feature_values=X_train["TIT"],
    labels=y_train,
    threshold=proposed_threshold,
)

4. Search for the best first split

Rather than specify one feature and cutpoint ourselves, the tree searches them. For each feature, candidate cutpoints lie halfway between adjacent distinct observed values.

The function below sorts one feature at a time, uses cumulative counts of positive labels, and scores every valid cutpoint. This gives the same greedy search logic as a decision-tree library while keeping the calculation practical for the full training dataset.

def find_best_gini_split(
    features: pd.DataFrame, labels: pd.Series
) -> dict[str, float | int | str]:
    """Find the feature and cutpoint with the smallest weighted Gini impurity.

    Args:
        features: Candidate feature columns for one parent region.
        labels: Binary labels for the same observations.
    Returns:
        Details of the best valid binary split in the region.
    """
    label_values = labels.to_numpy(dtype=int)
    n_samples = len(label_values)
    parent_gini = gini_impurity(labels=label_values)
    best_split: dict[str, float | int | str] | None = None

    for feature_name in features.columns:
        values = features[feature_name].to_numpy()
        order = np.argsort(values, kind="stable")
        sorted_values = values[order]
        sorted_labels = label_values[order]

        # A candidate cutpoint sits between two distinct adjacent values.
        left_sizes = np.arange(1, n_samples)
        right_sizes = n_samples - left_sizes
        left_positive = np.cumsum(sorted_labels)[:-1]
        right_positive = sorted_labels.sum() - left_positive
        valid = sorted_values[:-1] < sorted_values[1:]
        if not valid.any():
            continue

        left_fraction = left_positive / left_sizes
        right_fraction = right_positive / right_sizes
        left_gini = 2 * left_fraction * (1 - left_fraction)
        right_gini = 2 * right_fraction * (1 - right_fraction)
        weighted_gini = (
            left_sizes * left_gini + right_sizes * right_gini
        ) / n_samples

        candidate_index = np.where(valid, weighted_gini, np.inf).argmin()
        candidate_gini = float(weighted_gini[candidate_index])
        if best_split is None or candidate_gini < best_split["weighted child Gini"]:
            best_split = {
                "feature": feature_name,
                "threshold": float(
                    (sorted_values[candidate_index] + sorted_values[candidate_index + 1]) / 2
                ),
                "parent Gini": parent_gini,
                "weighted child Gini": candidate_gini,
                "Gini decrease": parent_gini - candidate_gini,
                "left samples": int(left_sizes[candidate_index]),
                "right samples": int(right_sizes[candidate_index]),
            }

    if best_split is None:
        raise ValueError("No split is available for this region.")
    return best_split

5. Choose the second split

After the first split, each child is a candidate for further division. A best-first tree asks which available child split delivers the largest overall reduction in training-set impurity. That requires weighting each child region’s local Gini decrease by the fraction of training observations that reach it.

We inspect this second split manually so the selection logic remains easy to follow. The next section generalizes the same search recursively.

root_feature = str(first_split["feature"])
root_threshold = float(first_split["threshold"])
left_mask = X_train[root_feature] <= root_threshold
right_mask = ~left_mask

left_candidate = find_best_gini_split(
    features=X_train.loc[left_mask],
    labels=y_train.loc[left_mask],
)
right_candidate = find_best_gini_split(
    features=X_train.loc[right_mask],

6. Build a tree recursively

The same split search can be repeated inside every child region. The recursive function below has one hyperparameter: max_depth, the maximum number of decision rules along any path from the root to a leaf. A value of 0 creates one leaf with no rules; a value of 2 permits up to two rules along a path.

The recursion stops when it reaches the requested depth, when all labels in a region agree, when all feature values in a region are identical, or when no split lowers Gini impurity.

def make_leaf(labels: pd.Series) -> dict[str, float | int | bool]:
    """Create a final prediction region.

    Args:
        labels: Binary labels in the final region.

    Returns:
        A dictionary representing one leaf of the tree.
    """
    positive_fraction = float(np.mean(labels))
    return {
        "is_leaf": True,
        "samples": len(labels),
        "positive fraction": positive_fraction,
        "prediction": int(positive_fraction >= 0.5),
    }


def build_tree(
    features: pd.DataFrame,
    labels: pd.Series,
    max_depth: int,
    depth: int = 0,
) -> dict[str, object]:
    """Build a binary classification tree by recursively reducing Gini impurity.

    Args:
        features: Candidate feature columns for the current region.
        labels: Binary labels for the current region.
        max_depth: Maximum number of decision rules from root to leaf.
        depth: Number of rules already used to reach the current region.

    Returns:
        A nested dictionary representing a decision tree.
    """
    no_feature_variation = features.nunique().eq(1).all()
    if (
        depth >= max_depth
        or labels.nunique() == 1
        or no_feature_variation
    ):
        return make_leaf(labels=labels)

    best_split = find_best_gini_split(features=features, labels=labels)
    if best_split["Gini decrease"] <= 0:
        return make_leaf(labels=labels)

    split_feature = str(best_split["feature"])
    split_threshold = float(best_split["threshold"])
    left_mask = features[split_feature] <= split_threshold
    right_mask = ~left_mask

    positive_fraction = float(np.mean(labels))
    return {
        "is_leaf": False,
        "samples": len(labels),
        "positive fraction": positive_fraction,
        "feature": split_feature,
        "threshold": split_threshold,
        "left": build_tree(
            features=features.loc[left_mask],
            labels=labels.loc[left_mask],
            max_depth=max_depth,
            depth=depth + 1,
        ),
        "right": build_tree(
            features=features.loc[right_mask],
            labels=labels.loc[right_mask],
            max_depth=max_depth,
            depth=depth + 1,
        ),
    }


def print_tree(node: dict[str, object], indent: str = "") -> None:
    """Print the decision rules and predictions in a tree.

    Args:
        node: Current node or leaf in the nested tree dictionary.
        indent: Text indentation used to show the tree structure.
    """
    if bool(node["is_leaf"]):
        print(
            f"{indent}Predict {node['prediction']} "
            f"({node['samples']} observations; "
            f"positive fraction = {node['positive fraction']:.3f})"
        )
        return

    feature = str(node["feature"])
    threshold = float(node["threshold"])
    print(f"{indent}If {feature} ≤ {threshold:.3f}:")
    print_tree(node=node["left"], indent=indent + "  ")
    print(f"{indent}Otherwise:")
    print_tree(node=node["right"], indent=indent + "  ")


scratch_tree = build_tree(features=X_train, labels=y_train, max_depth=2)

7. Build the same depth-limited tree with scikit-learn

The scikit-learn decision-tree implementation carries out this search efficiently. Setting max_depth=2 gives it the same depth limit used by our recursive implementation above. We use the same Gini criterion.

sklearn_tree = DecisionTreeClassifier(
    criterion="gini",
    max_depth=2,
    random_state=4520,
)
sklearn_tree.fit(X=X_train, y=y_train)

fig, ax = plt.subplots(figsize=(15, 7))
plot_tree(
    decision_tree=sklearn_tree,
    feature_names=FEATURES,
    class_names=["0", "1"],
    filled=True,
    rounded=True,
    impurity=True,
    proportion=False,
    precision=3,
    fontsize=12,
    ax=ax,

ax.set_axis_off()

8. Quantify feature importance

The depth-2 tree above is useful for inspecting individual rules, but it contains only a few splits. To make the importance profile richer, we fit a separate tree with max_depth=5. Scikit-learn provides a numerical importance for each feature through the feature_importances_ attribute.

  • At each split, measure how much the feature makes the child regions less mixed in their labels: the reduction in Gini impurity.
  • Weight that improvement by the number of observations reaching the split, so a helpful root split matters more than an equally helpful split in a small leaf.
  • Add these weighted improvements across every split using the same feature, then normalize them so that the importances sum to 1.

A value of 0.70 means that the feature accounts for 70% of this tree’s total weighted Gini reduction. It does not mean that the feature causes 70% of the outcome, or that it accounts for 70% of predictive accuracy. In practice, use held-out performance to choose the tree depth; we use depth 5 here only to make the example more informative.

importance_tree = DecisionTreeClassifier(
    criterion="gini",
    max_depth=5,
    random_state=4520,
)
importance_tree.fit(X=X_train, y=y_train)

feature_importance = pd.Series(
    data=importance_tree.feature_importances_,
    index=FEATURES,
    name="Gini importance",
).sort_values()

display(feature_importance.to_frame().round(3))

Advanced topics

This shallow tree is deliberately simple so that its rules are easy to inspect. In practice, several extensions matter:

  1. Tree complexity and overfitting. A deep tree can keep adding rules until it memorizes details of the training observations. Parameters such as max_depth, min_samples_split, and min_samples_leaf limit that complexity; choose them by performance on held-out data.
  2. Regression trees. For a continuous target such as NOx, a leaf predicts the average response in its region and splits can be chosen by reduction in mean squared error.
  3. Ensembles. Random forests and gradient-boosted trees combine many trees. They generally predict better than a single tree, at the cost of some interpretability.

Takeaways

  • A classification tree creates regions in feature space and assigns each leaf the majority class. The fraction of positive-label observations in a leaf also provides a simple probability estimate.
  • Each split greedily reduces weighted Gini impurity. It does not search jointly for every later split.
  • With max_depth=2, the recursion applies the same greedy split search independently within each child of the root.
  • Scikit-learn’s feature_importances_ attribute summarizes each feature’s share of the tree’s weighted Gini reduction; it is a predictive description, not a causal measure.
  • Trees can keep splitting until they memorize training observations, so later we will tune their depth and leaf-size controls using held-out data.
