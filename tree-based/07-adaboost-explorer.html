Explore AdaBoost

AdaBoost (Adaptive Boosting) builds an ensemble sequentially. It starts with equal weight on every training observation and fits a decision stump: a depth-1 tree with one split. Before fitting the next stump, it gives more weight to the samples the current stump misclassifies. Each later stump therefore pays more attention to earlier mistakes. We use stumps here deliberately to make that mechanism easy to see; AdaBoost can also use deeper trees as its base models.

TipWhat to watch

Add stumps one at a time. Every round uses the same training observations—not a bootstrap sample—but with a new set of observation weights. Compare the weight carried by the samples misclassified by the current stump before and after its update. Then inspect how the stumps cast weighted votes for one new observation and how held-out AUC changes across rounds.

Stumps fitted: 1/12
1

Fit one decision stump using the current weights

All original training observations remain in the dataset. Their current weights determine how strongly they influence this stump's split.

2

Give misclassified samples more influence

The next stump sees the same training samples, but not with equal weight. The samples this stump misclassifies are upweighted.

3

Pool weighted stump votes for one new observation

A more accurate stump receives a larger vote weight. With each stump prediction \(h_t(\mathbf{x})\) equal to 0 or 1, we compute the normalized positive vote

\[ s_T(\mathbf{x}) = \frac{\sum_{t=1}^{T} \alpha_t h_t(\mathbf{x})} {\sum_{t=1}^{T} \alpha_t}. \]

Because this is a weighted average, \(0 \leq s_T(\mathbf{x}) \leq 1\). It is a ranking score, however—not automatically a calibrated probability.

4

Evaluate the growing boosted ensemble

Every intermediate ensemble is evaluated against the same held-out observations. Each point includes all stumps up to that round.

The stump summaries, observation-weight changes, votes, and AUC values are precomputed from the gas-turbine data. The page reveals real fitted stumps; it does not train models in the browser.
