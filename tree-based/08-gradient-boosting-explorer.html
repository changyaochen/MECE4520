Explore gradient boosting

Gradient boosting also builds an ensemble sequentially, but it takes a different route from AdaBoost. Here, we predict continuous NOx concentration from six gas-turbine operating features. The model starts with one constant NOx prediction. Each new small regression tree then learns a continuous correction to the current prediction. With squared-error loss, the quantity it learns from is the ordinary residual \(r_i = y_i - \hat{y}_i\).

TipWhat to watch

Every stage uses the same training observations—there is no bootstrap sample and no observation-weight update. The new tree sees the current residuals: positive values mean the model underpredicts NOx, and negative values mean it overpredicts. Follow the tree’s correction for one held-out observation, then watch training and held-out MSE as stages are added.

1

Start with one constant model

Before any tree is fitted, every observation receives the average training NOx concentration.

2

Fit a shallow regression tree to the residuals

For each training observation, \(r_i = y_i - \hat{y}_i\). A positive residual calls for a higher NOx prediction; a negative residual calls for a lower prediction. The histogram uses one fixed residual scale across all stages, so its spread shows how much error remains for the next tree to correct.

3

Apply the correction to one new observation

The tree uses only the observation's features to add a continuous adjustment to the current NOx prediction. Its measured NOx is shown afterward only for comparison.

4

Evaluate the growing model

Each intermediate ensemble is evaluated against the same held-out observations. Training MSE shows fit to the training data; held-out MSE tells us whether the corrections generalize.

The residual histograms, fitted-tree rules, prediction corrections, and evaluation metrics are precomputed from the gas-turbine data. The page reveals real fitted trees; it does not train models in the browser.
