Explore a random forest

A random forest extends bagging. Like bagging, it fits many trees on bootstrap samples of one training dataset and averages their predictions. It adds a second source of diversity: at each split, a tree considers only a random subset of the available features.

TipWhat to watch

Add trees one at a time. Each tree receives a different bootstrap sample and, at every split, only a random subset of the features. Each tree is limited to depth 5, so it can vary without fitting every leaf perfectly. Inspect its root rule and held-out AUC. For the fixed new observation, compare the individual tree probabilities with their pooled average, then watch how the random forest’s held-out AUC changes as more trees are added.
