How a tree chooses a split

A binary classification tree builds a rule one decision at a time. At each node, it tries candidate cutpoints along every available feature, measures how much each candidate makes the two child regions purer, and selects the largest improvement.

TipFollow the search

This page makes the search explicit. Run the \(x_1\) loop and the \(x_2\) loop for the root node, select the winning split, and then repeat that process for each of its two children. The table records the Gini decrease for every candidate cutpoint that the tree evaluates.

For a region \(R\), the Gini impurity and the decrease from a candidate split are

\[ G(R) = 1 - \sum_{k=1}^{K} \hat{p}_{R,k}^{\,2}, \qquad \Delta G = G(R) - \left[ \frac{n_L}{n}G(R_L) + \frac{n_R}{n}G(R_R) \right]. \]

Here, a larger \(\Delta G\) is better.
