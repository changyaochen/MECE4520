How a fully grown tree can overfit

The same Gini-split procedure can be allowed to continue until every terminal region contains observations of only one label. This animation grows a tree on a slightly more mingled version of the mock dataset from the split explorer, with no limit on depth, no minimum leaf size, and no required minimum Gini decrease.

WarningPerfect training fit is not necessarily a good model

The final tree classifies all 16 observations correctly. But notice how it creates increasingly narrow regions to accommodate individual observations. That is a sign that the tree is memorizing this dataset and may not generalize well to new operating points.
