Explore backpropagation

Backpropagation computes how the loss changes with every trainable parameter. This explorer traces that calculation for one labeled observation, then applies the mean gradient from the entire toy dataset to update the network.

TipWhat to watch

Click a data point to choose the observation used in the visible trace. The network first makes a prediction, then carries the error signal backward to compute parameter gradients. A training update, however, uses the average gradient across all labeled observations.

    Layerwise gradients First compute an error signal for each layer, then use those signals to form the gradients for every parameter.
    Network shapes X ∈ ℝn×2, Y ∈ ℝn×1, W[1] ∈ ℝ3×2, b[1] ∈ ℝ1×3 → B[1] ∈ ℝn×3, Z[1], A[1] ∈ ℝn×3, W[2] ∈ ℝ1×3, b[2] ∈ ℝ1×1 → B[2] ∈ ℝn×1, Z[2], A[2] ∈ ℝn×1
    Hidden activation g(z) = max(0, z)   (ReLU),    g′(z) = 1 if z > 0; 0 otherwise elementwise
    Error signals δ[2] = A[2] − Y,    δ[1] = (δ[2]W[2]) ⊙ g′(Z[1])
    Output layer ∂L/∂W[2] = 1n (δ[2])TA[1],    ∂L/∂b[2] = mean(δ[2])
    Hidden layer ∂L/∂W[1] = 1n (δ[1])TX,    ∂L/∂b[1] = mean(δ[1])
