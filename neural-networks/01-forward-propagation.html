Neural networks: forward propagation

A neural network makes a prediction by repeatedly transforming its input. In this notebook, we trace those transformations for a small gas-turbine classification example. We use randomly generated weights: the goal is to understand forward propagation, not yet to learn the weights from data.

What you will do

  1. Turn a small batch of gas-turbine observations into a feature matrix.
  2. Compute a forward pass through one hidden layer with NumPy.
  3. Inspect the intermediate scores, activations, and predicted probabilities.
  4. See why an activation function changes what a stacked network can represent.
  5. Count the parameters created by changing the hidden-layer width.

1. Set up a small prediction batch

Each row in the course dataset is one gas-turbine operating observation. We use all nine measured operating features: AT, AP, AH, AFDP, GTEP, TIT, TAT, TEY, and CDP. They illustrate a binary prediction of the positive high_co label. CO itself is excluded because it defines that label.

We standardize the nine features so their numerical scales are comparable. This notebook does not fit or evaluate a model, so the standardization only makes the forward-pass calculation easy to inspect.

2. Define a network with one hidden layer

Our network has three hidden units and one output unit. For a batch of inputs, the forward pass is

\[ \begin{aligned} \mathbf{Z}^{[1]} &= \mathbf{X}(\mathbf{W}^{[1]})^T+\mathbf{B}^{[1]},\\ \mathbf{A}^{[1]} &= \operatorname{ReLU}(\mathbf{Z}^{[1]}),\\ \mathbf{Z}^{[2]} &= \mathbf{A}^{[1]}(\mathbf{W}^{[2]})^T+\mathbf{B}^{[2]},\\ \hat{\mathbf{p}} &= \sigma(\mathbf{Z}^{[2]}). \end{aligned} \]

Here, each row of \(\mathbf{W}^{[1]}\) holds the nine weights for one hidden unit, so \(\mathbf{W}^{[1]}\in\mathbb{R}^{3\times9}\). Similarly, \(\mathbf{W}^{[2]}\in\mathbb{R}^{1\times3}\) maps the three hidden activations to one output score. For this batch, \(\mathbf{B}^{[1]}\in \mathbb{R}^{4\times3}\) and \(\mathbf{B}^{[2]}\in\mathbb{R}^{4\times1}\) repeat the learned biases for each observation. The sigmoid converts each final score to a number between 0 and 1.

def sigmoid(values: np.ndarray) -> np.ndarray:
    """Map output scores to values between zero and one.

    Args:
        values: Array of real-valued output scores.

    Returns:
        Array with the same shape as `values`, with entries in [0, 1].
    """
    return 1 / (1 + np.exp(-values))


def relu(values: np.ndarray) -> np.ndarray:
    """Apply the rectified linear-unit activation elementwise.

    Args:
        values: Array of hidden-layer scores.

    Returns:
        Array with negative entries replaced by zero.
    """
    return np.maximum(values, 0)


def identity(values: np.ndarray) -> np.ndarray:
    """Return hidden-layer scores unchanged.

    Args:
        values: Array of hidden-layer scores.

    Returns:
        The input array, unchanged.
    """
    return values

Package the calculation in a function

The two cells above are the complete forward pass. Now that each operation is visible, we can wrap the same sequence in a reusable function. The function should give exactly the same arrays as the explicit calculation.

def forward_pass(
    *,
    X: np.ndarray,
    weights_hidden: np.ndarray,
    bias_hidden: np.ndarray,
    weights_output: np.ndarray,
    bias_output: np.ndarray,
    activation: Callable[[np.ndarray], np.ndarray],
) -> dict[str, np.ndarray]:
    """Compute one forward pass through a one-hidden-layer network.

    Args:
        X: Input feature matrix with shape (n_observations, n_features).
        weights_hidden: Hidden-layer weights with shape
            (n_hidden_units, n_features).
        bias_hidden: Broadcast hidden biases, with shape
            (n_observations, n_hidden_units).
        weights_output: Output-layer weights with shape
            (1, n_hidden_units).
        bias_output: Broadcast output bias with shape
            (n_observations, 1).
        activation: Elementwise hidden-layer activation function.

    Returns:
        Dictionary containing the hidden scores, hidden activations, output
        scores, and positive-label probabilities.
    """
    hidden_scores = X @ weights_hidden.T + bias_hidden
    hidden_activations = activation(hidden_scores)
    output_scores = hidden_activations @ weights_output.T + bias_output
    probabilities = sigmoid(output_scores)

    return {
        "hidden_scores": hidden_scores,
        "hidden_activations": hidden_activations,
        "output_scores": output_scores,
        "probabilities": probabilities,
    }


relu_outputs = forward_pass(
    X=X_batch,
    weights_hidden=weights_hidden,
    bias_hidden=bias_hidden,
    weights_output=weights_output,
    bias_output=bias_output,
    activation=relu,
)

5. Why the activation function matters

A hidden layer without a nonlinear activation cannot create a more flexible function. If we replace ReLU with the identity function, the two linear layers collapse into one effective linear score before the final sigmoid.

We can verify that numerically.

identity_outputs = forward_pass(
    X=X_batch,
    weights_hidden=weights_hidden,
    bias_hidden=bias_hidden,
    weights_output=weights_output,
    bias_output=bias_output,
    activation=identity,
)

effective_weights = weights_output @ weights_hidden
effective_bias = bias_hidden @ weights_output.T + bias_output
collapsed_probabilities = sigmoid(
    X_batch @ effective_weights.T + effective_bias
)

np.testing.assert_allclose(
    actual=identity_outputs["probabilities"],
    desired=collapsed_probabilities,
)

activation_comparison = pd.DataFrame(
    {
        "ReLU hidden layer": relu_outputs["probabilities"].ravel(),
        "identity hidden layer": identity_outputs["probabilities"].ravel(),
        "collapsed linear network": collapsed_probabilities.ravel(),
    },
    index=[f"source row {row}" for row in BATCH_ROWS],
)

print("The assertion passed: the identity network matches one linear score plus sigmoid.")
activation_comparison.round(3)

The ReLU network does not collapse in this way because it changes values depending on whether each hidden score falls above or below zero. That nonlinearity lets neural networks represent nonlinear relationships.

6. Count the parameters

For \(p\) input features, \(h\) hidden units, and one output unit, this network has \(ph+h+h+1\) parameters: hidden weights and biases, then output weights and bias. Increasing hidden-layer width increases the model’s capacity and also increases the number of quantities that later need to be learned.

def count_parameters(*, n_features: int, n_hidden_units: int) -> int:
    """Count parameters in a one-hidden-layer binary classifier.

    Args:
        n_features: Number of input features.
        n_hidden_units: Number of hidden units.

    Returns:
        Total number of weights and biases in the network.
    """
    hidden_layer = n_features * n_hidden_units + n_hidden_units
    output_layer = n_hidden_units + 1
    return hidden_layer + output_layer

Takeaways

  • Forward propagation carries each observation through weighted sums and activation functions to produce a prediction.
  • With one row per observation, matrix shapes reveal how an entire batch can move through the network at once.
  • ReLU allows stacked hidden layers to avoid collapsing into one linear model.
  • The next question is how to choose the weights and biases from data. That requires a loss function and backpropagation.
