# MECE 4520: Data Science for Mechanical Systems

This repository contains the course materials and website source for Columbia
University's MECE 4520, *Data Science for Mechanical Systems*.

The [course website](https://changyaochen.github.io/MECE4520/) is the source of
truth for current course information, including the syllabus, grading policy,
schedule, staff, and student-facing materials.

## Course focus

MECE 4520 introduces data science and machine learning through real mechanical
engineering systems. Students work with recurring engineering datasets and use
them to build predictive models, diagnose systems, learn representations, and
study sequential decision-making and reinforcement learning.

## Repository

- `site/` contains the Quarto source for the course website.
- `docs/` records redesign decisions for the Fall 2026 pilot.
